TokenRhythm for Copilot Chat uses your own TokenRhythm API key to make a variety of AI models available in the model picker.

Paste it once, then update or remove it later from the Command Palette.

- `Cmd/Ctrl + Shift + P`: Open the Command Palette
- `TokenRhythm: Set TokenRhythm API Key`: Set or update your API key
- `TokenRhythm: Generate Commit Message with TokenRhythm`: Generate Git commit messages

[Get an API Key](https://tokenrhythm.studio)
[Set API Key](command:tokenrhythm.setApiKey)
