TokenRhythm models should appear in the Copilot model picker as soon as the extension is active. If an API key is not configured yet, they show a warning icon until you run `TokenRhythm: Set TokenRhythm API Key`.

If you do not see them right away, the model list may simply be long. Scroll down in the picker and look for models under the **TokenRhythm** family, or open the Language Models manager to check:

[Open Language Models](command:workbench.action.chat.manage)
